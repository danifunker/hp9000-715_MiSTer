## How to work

* Board: `tools/mister/board.sh push|load|setup|console|type|shot`;
  `tools/mister/trace_dump.py dump` on the MiSTer (copy it to
  `/media/fat/hp715dbg/`) shows interruptions (it found build 16's trap).
  The serial console is quiet with the graphics console (HP-UX's console is
  the ITE). Shut HP-UX down (`shutdown -h -y 0` as root, over a serial
  login or on the graphics console) before loading a new core.
* romsim: `make -C verilator romsim ROMSIM_DIR=obj_dir_rom_<name>`; graphics
  boots need `+eeprom=` a graphics-console image; `--fbshot` for pictures,
  `--ps2` to type. Gates: `make -C verilator tb_artist`, `tests/run-rom.sh`
  (passes with Artist present); CPU gates only after a CPU change the user
  asked for.
* Quartus: `quartus_sh --flow compile HP9K715` with `setsid nohup`, ~30-35
  min, one flow at a time (`pgrep -a quartus`).
* Rules (CLAUDE.md, memory): commit often with explicit paths, every stub in
  `docs/STUBS.md`, never delete anything without asking, show the user
  screenshots as things move, release notes in the root README.
